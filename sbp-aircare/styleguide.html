สี

โมดูลร่วม (shared.css, studio.css, services.css และ UI ที่สร้างจาก JavaScript) ใช้ได้เฉพาะ token ชุดนี้ แต่ละแบบกำหนดค่าเองใน :root ของหน้า ตัวเลขคือคอนทราสต์เทียบพื้นการ์ด (ตัวอักษรบนปุ่มหลัก เทียบสีปุ่ม)

4.5 ขึ้นไป ผ่าน AA ทุกขนาด3–4.5 ผ่านเฉพาะตัวอักษรใหญ่ต่ำกว่า 3 ไม่ผ่าน

ตัวอักษร

ขนาดที่วัดได้จริงบนจอ 1366 และ 390 พิกเซล กติกา: ชื่อหน้า (h1) ใหญ่กว่าหัวข้อส่วน (h2) เสมอ · ข้อความไทยไม่ต่ำกว่า 12.5 พิกเซล · เนื้อความ 16 พิกเซล ระยะบรรทัด 1.7

ชิ้นส่วนร่วม ทุกแบบ ทุกธีม

ชิ้นส่วนจริงจาก shared.css วางบน token ของแต่ละแบบ ตัวเลขราคามาจาก Pricebook ชุดเดียวกับเว็บ (ล้างติดผนังขนาดเล็ก 2 เครื่อง + ยอดขั้นต่ำงานล้าง)

กติกาก่อนส่งงาน

  1. คอนทราสต์ 4.5:1 ทุกตัวอักษรในทั้งสองธีม · สถานะห้ามบอกด้วยความจางอย่างเดียว · token สีตัวอักษรทุกตัว (รวม ok warn bad) ต้องกำหนดใหม่ในบล็อกมืดทั้งสองบล็อก · ตรวจ BASE=http://localhost:8765 node tests/axe.mjs a light
  2. ตัวอักษรขั้นต่ำ 12 พิกเซล (ภาษาไทย 12.5) ยกเว้นป้ายบนภาพ 3 มิติและตัวเลขใน SVG · เป้ากดบนจอสัมผัส 44 พิกเซลขึ้นไป · ตรวจ node tests/audit.mjs c 390 dark 3
  3. หัวหน้าทุกหน้า h1 ใหญ่กว่า h2 · หัวข้อไม่ข้ามระดับ · มี main เดียว · หัวข้อภาษาไทยผ่าน typeset.thaiPhrases (ไม่ฉีกคำ)
  4. ไม่เลื่อนแนวนอน ที่ 1366 และ 390 · ตารางกว้างเลื่อนในกรอบของตัวเองและกดโฟกัสด้วยคีย์บอร์ดได้ · เมนูหลักไม่ล้นทุกความกว้าง
  5. การเคลื่อนไหว เฉพาะภาพ 3 มิติที่มีความหมาย · เคารพ prefers-reduced-motion · ไม่มีเอฟเฟกต์ลอยขึ้นทีละหัวข้อ · ไม่มี "→" ท้ายปุ่ม · ป้ายควบคุมเป็นภาษาไทย
  6. โมดูลร่วม ใช้เฉพาะ alias token ในหน้านี้ · ชื่อคลาสมี prefix ของโมดูล (s- st- sv- hw- ts- sy3- qk- …) ห้ามชื่อทั่วไปที่ชนกับหน้า
  7. ราคาและข้อความ ราคาเดียว ก่อน VAT หลักร้อย · คำต้องห้ามตาม CLAUDE.md §6.6 #11 · ภาพจำลองมีคำว่า "แบบจำลองเพื่ออธิบาย" · ห้ามบอกว่า "ส่งแล้ว" จนกว่าหลังบ้านตอบเลขที่คำขอ · ตรวจ npm run textscan และ npm run pricing
