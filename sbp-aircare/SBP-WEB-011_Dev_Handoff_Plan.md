## 1. เป้าหมายของเว็บ

1. **ปิดสัญญาล้างรายปี B2B เป็นจำนวน** ลูกค้าเห็นราคาต่อปีจาก Pricebook จริงได้เอง แล้วใส่ใบเสนอราคาได้ทันที
2. **ขายแอร์ทุกรุ่นพร้อมราคา** ราคาเครื่อง ราคาพร้อมติดตั้ง และราคาอุปกรณ์เพิ่ม รวมยอดให้เองก่อนติดต่อทีม
3. **ค่าบริการโปร่งใสครบทุกหมวด** ล้าง ติดตั้ง ซ่อม รื้อ/ย้าย วัสดุ พร้อมสิ่งที่รวม ไม่รวม และรับประกัน
4. **ตัดคำถามซ้ำของทีมขาย** ใบเสนอราคาเบื้องต้นส่งรายการ พื้นที่ ค่าเดินทาง และยอดรวมมาให้ครบ

5. **ให้ลูกค้าเห็นภาพก่อนตัดสินใจ** เลือกห้องแบบของตัวเอง เห็นลมเย็น ฝุ่น และผลของการไม่ล้าง แล้วได้รุ่นพร้อมราคาและแผนล้างทันที

## 6K. แบบ A — แอร์ทำงานอย่างไร 3 มิติ (howitworks3d.js + hw-data.js — Rev.06)

- ห้องจำลองมีผนังนอกโปร่งแสง ฝ้า เฟอร์นิเจอร์ คน คอยล์ร้อนนอกอาคาร ท่อน้ำยาเส้นใหญ่/เล็ก ท่อน้ำทิ้ง เดินตามแนวจริงของแต่ละประเภท

  - **ติดผนัง:** ลมเข้าด้านบน → ฟิลเตอร์ → คอยล์เย็นพับ → พัดลมกรงกระรอกยาว (cross-flow) → บานสวิงล่าง, ถาดน้ำทิ้งใต้คอยล์ไหลออกด้วยแรงโน้มถ่วง
  - **แขวนใต้ฝ้า:** ลมเข้าตะแกรงใต้ท้องด้านหลัง → ฟิลเตอร์ → พัดลมซีร็อกโค (ใบถี่ในโข่ง) หลายตัวบนแกนเดียว → คอยล์เย็นเอียง → เป่าออกด้านหน้าไกล
  - **สี่ทิศทาง (ฝังฝ้า):** ลมเข้าตรงกลางหน้ากาก → ฟิลเตอร์ → ปากแตร (bell-mouth) → พัดลมเทอร์โบ เหวี่ยงออกด้านข้าง → คอยล์เย็นล้อมรอบ 4 ด้าน → ออก 4 ช่อง, **ปั๊มน้ำทิ้ง + ลูกลอย** ยกน้ำขึ้นท่อน้ำทิ้งเหนือฝ้า
- 7 ขั้นต่อประเภท (ลมกลับ, ฟิลเตอร์, คอยล์เย็น, น้ำทิ้ง, พัดลม, ลมออก, คอยล์ร้อน) — กดเล่นอัตโนมัติ หรือกดทีละขั้น กล้องบินไปที่ชิ้นส่วน **ภาพตัดผ่ากลางเครื่อง** + ชิ้นอื่นจางลง + ป้ายเลขกำกับ
- อนุภาค: ลมร้อนในห้อง (ส้ม) → ลมเย็นออก (ฟ้า), หยดน้ำ, น้ำยาเย็น/ร้อนในท่อ · สวิตช์ X-ray และชั้นข้อมูล (ลม / น้ำยา / น้ำทิ้ง)

## 6P. ข้างในเครื่อง 0–18 เดือน + ค่าไฟ (studio.js — Rev.07)

- **4 แผงภาพ:** แผ่นกรอง (ฝุ่นหนาขึ้นจนทึบ) · หน้าตัดคอยล์ (ครีบถูกฝุ่นอุดช่องลม) · ใบพัด (คราบดำ/เชื้อราเกาะขอบใบ) · ถาดน้ำทิ้ง (เมือก → น้ำเอ่อล้น) — เลื่อน 0–18 เดือน ภาพเปลี่ยนตามอัตราฝุ่นของห้อง
- **ตัวเลขข้างภาพ:** ลมที่เหลือ % · ความเย็นที่ได้ % · ไฟต่อความเย็นเดิม % · กราฟ 0–18 เดือน 3 เส้น + แถบรอบล้างแนะนำ
- **การ์ดค่าไฟ:** ห้องนี้ + 4 ขนาดเครื่อง (9k/12k/18k/24k หรือตามประเภท) × Inverter/ธรรมดา × ชั่วโมงเปิด (เลื่อนได้) × ค่าไฟต่อหน่วย (แก้ได้) → ค่าไฟ/เดือนตอนสะอาด vs ตอนนี้ + ส่วนต่อ/ปี เทียบราคาล้าง Basic Clean C1 จาก Pricebook + กล่อง "พูดตรง ๆ" (ห้องเปิดน้อยชั่วโมง ค่าล้างอาจมากกว่าไฟที่ประหยัดได้ — เหตุผลหลักคือกลิ่น ความเย็น และอายุเครื่อง)

```
kWh/วัน = BTU ÷ ประสิทธิภาพ(BTU/h ต่อ W) ÷ 1000 × ชั่วโมงเปิด × 0.65 (ภาระเฉลี่ยของคอมเพรสเซอร์)
  ประสิทธิภาพสมมติ: Inverter ติดผนัง 18 · Inverter ประเภทอื่น 14 · ธรรมดา ติดผนัง 12.5 · ธรรมดา อื่น 11.5
ค่าไฟตอนนี้ = kWh ตอนสะอาด × (1 + 0.15 × ฝุ่น) × ค่าไฟต่อหน่วย (บ้าน 4.62 · ธุรกิจ 4.9 บาท/หน่วย รวม Ft + VAT โดยประมาณ)
ลม = 1 − 0.35 × ฝุ่น · ความเย็น = 1 − 0.2 × ฝุ่น   (ฝุ่น 1 = เครื่องที่สกปรกหนักมาก)
```
ที่มาของช่วงตัวเลข: US DOE (แผ่นกรองตันเพิ่มการใช้ไฟ 5–15%), งานวิจัยคอยล์อุดตัน 30% ลดความสามารถทำความเย็น ~19% (Energy & Buildings 2024), ACEEE 2002, บทความ กฟผ./PEA เรื่องล้างแอร์ช่วยประหยัดไฟ, อัตราค่าไฟงวด ก.ย.–ธ.ค. 2569 · **ทุกตัวเลขเป็นค่าประมาณเพื่ออธิบาย ห้ามสื่อว่าประหยัดไฟแน่นอน** — ข้อความกำกับอยู่ใต้การ์ด

## 6U. ตัวเครื่องเต็ม (มองทะลุ) + แนวท่อในรางครอบท่อ (howitworks3d.js + trunk3d.js — Rev.07.2)

- **เลิกภาพผ่าครึ่งเครื่อง** — แสดงตัวเครื่องเต็มทุกประเภท ฝาครอบ/หน้ากากเป็นกระจกใส (ทึบ 12%) พร้อมเส้นขอบคม ยังเห็นรูปทรงจริงและกลไกข้างในพร้อมกัน · สวิตช์ "มองทะลุตัวเครื่อง" ปิดเพื่อดูเครื่องทึบได้ · ป้ายชื่อชิ้นส่วนยึดตำแหน่งจริงของชิ้นส่วน (ไม่ต้องใช้จุดบนหน้าตัดแล้ว)
- **`trunk3d.js` (ใหม่):** `buildTrunk(centreLine, lidNormals, { caps, W, D })` สร้างรางครอบท่อสีขาว 75 มม. (ฐาน + ฝา มีเส้นรอยต่อฝา) · ทุกมุมใส่ข้อต่อจริง: ข้องอแบน 90° (มุมในระนาบผนัง) · ข้องอฉาก (มุมที่เปลี่ยนผิวยึด เช่น ใต้ฝ้า → ผนัง) · ข้องอ 45° (หลบแนวเฉียง) · ฝาครอบผนังตรงจุดทะลุผนัง · ฝาปิดปลายราง · `bentPath()` ดัดท่อเป็นมุมฉากรัศมีเล็กแบบท่อทองแดงจริง (ไม่ใช่เส้นโค้งมั่ว) · `pipeHanger()` สตัดแขวนท่อเหนือฝ้า
- **แนวท่อตามประเภท:**
  - ติดผนัง: ท่อ + สายน้ำทิ้ง (ย้ายมาออกซ้ายหลังเครื่อง) ลงรางใต้เครื่อง → ข้องอ 45° × 2 หลบเฉียง → วิ่งตรงตามผนัง → ฝาครอบผนัง → ข้องอแบน 90° ลง → ฝาปิดปลาย → ดัดท่อเข้าวาล์วคอยล์ร้อนเป็นมุมฉาก (ท่อใหญ่ข้ามเหนือท่อเล็ก ไม่ชนกัน) · น้ำทิ้งออกปลายรางลงจุดระบาย
  - แขวนใต้ฝ้า: ออกหลังเครื่องเข้ารางช่วงสั้นใต้ฝ้า → ข้องอฉากชิดผนัง → ตามแนวผนัง → ฝาครอบผนัง → ข้ามเหนือคอยล์ร้อน → ข้องอแบน 90° ลง → วาล์ว · สายน้ำทิ้ง PVC ลาดจากเครื่องถึงผนังแล้วลงในรางเส้นเล็กแยก
  - สี่ทิศทาง: เหนือฝ้าเดินท่อหุ้มฉนวนเป็นมุมฉากแขวนสตัด (ปั๊มยกน้ำแล้วไหลลาดไปกับท่อ) → ทะลุผนังที่ฝาครอบผนัง → รางด้านนอกลง → ข้องอ 45° หลบ → ฝาปิดปลาย → วาล์วคอยล์ร้อนที่ตั้งชิดผนัง
- คอยล์ร้อนทุกประเภทหันตรงแนวผนัง (ไม่วางเอียง) หลังชิดผนัง ระยะตามจริงโดยประมาณ · ขั้นที่ 7 มีป้าย รางครอบท่อ / ข้องอ 90° / ข้องอ 45° / ฝาครอบผนัง
- ห้องจำลอง: ซ่อนท่อที่ห้อยใต้แอร์ติดผนัง (ถือว่าท่อเข้าผนังหลังเครื่อง) เพื่อไม่ให้ภาพดูเป็นงานไม่เรียบร้อย
- มือถือ: คำอธิบายขั้นย่อ 3 บรรทัด แตะเพื่ออ่านทั้งหมด (ไม่บังภาพ)

### 6V.2 ขั้นตอนช่าง (แบบ C) — ยึดแบบฟอร์มบริษัท

- **ล้างปกติ C1 (14 ขั้น):** ยืนยันเครื่องและตรวจก่อนเริ่ม → วัดค่าก่อนล้าง (T2) → ตัดไฟ RCBO และตรวจยืนยัน → คลุมพื้น ผนัง แผงวงจร → บันทึกจุดยึด ถอดหน้ากาก แผ่นกรอง บานสวิง → ฉีดน้ำยาล้างคอยล์ → ล้างคอยล์ด้านหน้าด้วยน้ำแรงดัน (ถุงรองน้ำล้าง) → ล้างโบลเวอร์เท่าที่เข้าถึง → ล้างถาด/ทะลวงทางน้ำทิ้ง → ล้างคอยล์ร้อนจากภายนอก → เป่าแห้ง ตรวจฉนวน ประกอบกลับ → เปิดไฟ ทดสอบ T1 + น้ำทิ้ง → วัดค่าหลังล้าง (T2) → ส่งมอบ ภาพก่อน–หลัง เกรด A–D รอบถัดไป
- **ล้างใหญ่ C2 (17 ขั้น):** เพิ่ม ปลดคอยล์เย็นลดระดับลง **ไม่ตัดท่อน้ำยา** → ถอดใบพัดโบลเวอร์/ถาดน้ำทิ้ง + **ลงทะเบียนชิ้นส่วน (บังคับ)** → ล้างแผงคอยล์ด้านหลัง → ล้างชิ้นส่วนนอกตัวเครื่อง → แขวนเครื่องกลับเข้าที่
- **ติดตั้ง (13 ขั้น):** สำรวจและวางแนวท่อ → ตรวจรับเครื่อง (Model/Serial จากป้ายจริง) → ยึดแผ่นยึดได้ระดับ เจาะผนัง → ติดรางครอบท่อ Airpro + ข้องอ/ฝาปิดปลาย → ตั้งคอยล์ร้อน + ยางกันสั่น → เดินท่อ ท่อน้ำทิ้ง สายไฟลงราง → แขวนคอยล์เย็น ต่อแฟลร์ → ต่อแฟลร์วาล์วคอยล์ร้อน + ระบบไฟ → **ทดสอบรอยรั่ว** (มาตรฐาน: ตรวจรอยต่อแฟลร์ · พรีเมียม: อัดไนโตรเจนค้างตามเวลา) → **ทำสุญญากาศ** → เปิดวาล์ว เดินเครื่อง วัดค่า → ทดสอบน้ำทิ้ง ปิดฝาราง เก็บงาน (Punch list) → ส่งมอบ สอนใช้งาน ลงนาม 3 ฝ่าย + รับประกัน 3 ปี (ซื้อเครื่องจากบริษัท) / 1 ปี (ลูกค้าจัดหาเครื่องเอง)
- **ตรวจซ่อม (10 ขั้น):** รับแจ้งอาการ → ตรวจความปลอดภัยก่อนเปิดเครื่อง → เดินเครื่องดูอาการ/Error Code → ตรวจแผ่นกรอง คอยล์ ถาด ท่อน้ำทิ้ง → วัดอุณหภูมิลมกลับ–ลมจ่าย → วัดกระแส/แรงดัน → ตรวจคอยล์ร้อน → ตรวจระบบน้ำยา (A4 เมื่อจำเป็น) → **แจ้งผลและราคารายรายการ ไม่ซ่อมก่อนอนุมัติ** → ซ่อม ทดสอบ ส่งรายงาน
- **ค่าที่แสดงในชิป** (เช่น ΔT กระแส micron psi) เป็น "ตัวอย่างการบันทึก" ทุกจุด ข้อความกำกับ: *"ช่างกรอกค่าที่วัดได้จริง · ตัวเลขเป็นตัวอย่างการบันทึก ไม่ใช่เกณฑ์ผ่าน/ไม่ผ่าน"* — ห้ามนำไปใช้เป็นเกณฑ์ตัดสิน ให้ใช้ค่าตามคู่มือผู้ผลิตของรุ่นนั้น
- ลมเย็น/ลมร้อนเป็นเส้นอนุภาคไหลจริงตามทิศบานสวิง (แสดงเฉพาะขั้นที่เครื่องเดิน) · ปิดลมระหว่างตัดไฟ/ถอดชิ้นส่วน

## 8. Contract Builder — ใช้อัตรา Pricebook จริง

```
อัตราต่อเครื่อง = CleanRate(แพ็กเกจ, C1 หรือ C2, ประเภท, ช่วง BTU ตาม "ขนาดเครื่องส่วนใหญ่")
คอลัมน์อัตรา   = อัตรามาตรฐานเท่านั้นบนเว็บ (≥10 เครื่องแสดงข้อความว่าอาจได้อัตราพิเศษ ทีมขายยืนยันในใบเสนอราคา)
ต่อรอบ          = max(Σ อัตรา × จำนวน, ยอดขั้นต่ำ 4,500)
ต่อปี            = รอบล้างปกติ × (ครั้งต่อปี − 1) + รอบล้างใหญ่ × 1 (ถ้าเลือก) + ค่าเดินทาง × ครั้งต่อปี
แสดงผล          = ราคาต่อปีรวม VAT, ก่อน VAT, เฉลี่ยต่อเครื่องต่อปี, ตารางอัตราต่อประเภท
```

- งานสูงเกิน 3 ม. พื้นที่ควบคุม เครื่องที่เข้าถึงยาก → แสดงเป็นหมายเหตุ "ประเมินหน้างาน"
- **ด่านกันขาดทุน (ภายใน ห้ามส่งถึง browser):** ตรวจยอดต่อทีม-วันเทียบพื้นราคาขั้นต่ำตามนโยบาย (Approval Matrix ในคู่มือทีมขาย) และต้นทุนเต็ม (SBP-MGR-001) — ทั้งสองค่าเก็บเป็น config ฝั่ง server เท่านั้น ไม่ระบุตัวเลขในเอกสารที่ส่งออกนอกบริษัท ถ้าต่ำกว่าให้แสดง "ทีมขายประเมิน" แทนตัวเลข
- "กำลังคนต่อรอบ" ใช้กำลังทีมจากคู่มือบริษัท §1.9: ติดผนัง 22 · แขวน/สี่ทิศทาง/ตู้ตั้ง 14 · ท่อลม 12 เครื่อง/ทีม-วัน (งานล้างปกติ C1)

- **Performance (มือถือ 4G):** LCP < 2.5s, CLS < 0.1, JS หน้าแรก ≤ 200KB gzip ก่อนโหลด 3D, 3D โหลดหลัง interaction หรือเข้าใกล้จอ
- **Theme:** ทุกสีเป็น token มีทั้งสว่าง/มืด (ต้นแบบรองรับ `prefers-color-scheme` และ `data-theme`)
- **Mobile:** bottom action bar 4 ปุ่ม [เมนู] [โทร] [LINE] [ใบเสนอราคา + จำนวนรายการ] ติดล่างทุกหน้า
- **ความจริงของข้อมูล:** ราคาทุกตัวบนเว็บต้องมาจาก Pricebook ที่อนุมัติแล้ว ไม่มีตัวเลขสถิติ รีวิว หรือโลโก้ลูกค้าในเฟสนี้

## 13. เรื่องที่ยังค้างก่อน Sprint 1

เรื่องราคา พื้นที่ และรอบล้างใช้ค่ามาตรฐานตามตาราง 0 ข้อ 10–19 แล้ว เหลือเรื่องต่อไปนี้ (ข้อ 7–10 เพิ่มใน Rev.07)

1. **เลือกแบบ A · B · C** — ทดสอบในหน้าทดสอบ A B C (ไฟล์เดียว, รายการทดลอง 11 ข้อ) ให้คะแนน 6 ด้าน (สวยงาม, ใช้ง่าย, น่าเชื่อถือสำหรับองค์กร, เหมาะกับลูกค้าบ้าน, ห้องจำลอง/3D, มือถือ) ทุกแบบใช้โมดูลฟีเจอร์เดียวกัน จึงยืมจุดเด่นข้ามแบบได้
2. **ราคา FUJIVA ทุกรุ่น** เพื่อนำเข้า Pricebook (เว็บแสดง "ราคาและรุ่นกำลังจะขึ้นเว็บ · สอบถามทีมขาย")
3. **ห้องน้ำ:** ต้นแบบให้เลือกได้แต่บังคับขึ้นคำแนะนำให้สำรวจก่อน — ยืนยันว่าบริษัทรับติดตั้งในพื้นที่ชื้นหรือไม่
4. **อัตราฝุ่นและตัวคูณแดด/หลังคา** ในห้องจำลองเป็นค่าตั้งต้นเพื่ออธิบาย ควรปรับจากข้อมูลงานล้างจริง 3–6 เดือนก่อนเปิดใช้
5. **ห้องพักผู้ป่วยและห้องควบคุมอากาศพิเศษ** — ยืนยันขอบเขตที่บริษัทรับ (ต้นแบบขึ้น "ต้องสำรวจก่อน")
6. **ไฟล์ 3 มิติ / ภาพทางการจากผู้ผลิต (Daikin, Carrier ฯลฯ)** — ถ้าต้องการโชว์เครื่องยี่ห้อจริงบนเว็บ ต้องขอไฟล์และสิทธิ์ใช้งานเชิงพาณิชย์เป็นลายลักษณ์อักษรจากผู้ผลิต/ผู้แทนจำหน่าย ห้ามปั้นเลียนแบบเอง · ได้ไฟล์ .glb แล้วใส่ช่อง `loadModel` ได้ทันที (หัวข้อ 6M)
7. **Pricebook: K Copper → O-TWO (28 จุด)** และเลิกใช้ระดับติดตั้งพื้นฐาน (-MASS) ในใบเสนอราคาลูกค้าทั่วไป — ตามคำตัดสินข้อ 16–17 (เว็บแปลงให้แล้ว แต่เอกสารขายต้องตรงกัน)
8. **โลโก้และเอกสารสเปกวัสดุ** O-TWO · Aeroflex · Airpro · Yazaki · SCG · NANO — ขอไฟล์โลโก้ + หนังสืออนุญาตใช้บนเว็บจากผู้แทนจำหน่าย (6S)
9. **ความหนาท่อกับน้ำยา R32** — ให้หัวหน้าช่างยืนยันตารางความหนาท่อตามคู่มือผู้ผลิตที่ขายอยู่ ถ้ามีขนาดที่ต้องหนากว่า 0.70 มม. ให้เพิ่มรายการใน Pricebook · **(Rev.08) โดยเฉพาะท่อ 7/8" ในชุดเหมา PIP-PKG-3878** ซึ่งเว็บไม่ระบุความหนาไว้
10. **ประสิทธิภาพและค่าไฟในห้องจำลอง** เป็นค่าสมมติจากช่วงงานวิจัย ควรเทียบกับค่าที่ทีมวัดจริงก่อน–หลังล้าง (T2) 20–30 เครื่องก่อนใช้ในการขาย
11. **(Rev.08) นำราคาชุดใหม่ SBP-PRC-001 ขึ้นเว็บ** — ยังไม่ได้ทำ ระบบตรวจความปลอดภัยไม่อนุญาตให้แก้ราคาบนเว็บโดยไม่มีการยืนยันชัดเจนจากเจ้าของ เว็บทั้ง 3 แบบจึงยังใช้ราคาชุดเดิม (กระทบยอดผิด 0) — เมื่อเจ้าของยืนยันเป็นลายลักษณ์อักษร ให้แก้ที่ `sbp-data.json` จุดเดียว แล้วรัน `tools_recon.py` เทียบใหม่
12. **(Rev.08) ภาพ/วิดีโองานจริงของทีม** — ภาพ 3 มิติเป็นแบบจำลองเพื่ออธิบาย ควรมีภาพถ่ายงานจริงของบริษัท (ก่อน–หลังล้าง, งานรางครอบท่อ, การทดสอบสุญญากาศ) อย่างน้อยงานละ 3–5 ภาพ เพื่อความน่าเชื่อถือกับลูกค้าองค์กร
13. **(Rev.08) มือถือรุ่นเก่า** — ฉาก 3 มิติชุดใหม่หนักขึ้น ควรทดสอบบนมือถือ Android ระดับล่างจริง 2–3 เครื่องก่อนเปิด ถ้ากระตุก ให้แสดงภาพนิ่งแทนอัตโนมัติ
