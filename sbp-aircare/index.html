6A. ฟังก์ชันการขายและราคา (ครบในต้นแบบทั้ง 3 แบบ)

หน้าสินค้า (ต่อรุ่น)

  1. ราคาเครื่องรวม VAT + ก่อน VAT, สถานะราคา (อนุมัติ/อ้างอิง), สถานะสต็อก
  2. สลับขนาด BTU ในซีรีส์เดียวกัน
  3. แพ็กเกจติดตั้ง: พื้นฐาน / มาตรฐาน / พรีเมียม / ไม่ติดตั้ง (ราคาตามประเภทและช่วง BTU จริง) พร้อม "รวม / ไม่รวม / รับประกัน"
  4. อุปกรณ์เสริมตามขนาดเครื่อง: ชุดท่อส่วนเกินต่อเมตร (6 ขนาดท่อ), ท่อน้ำทิ้ง, เมนไฟ 3 ขนาดสาย, RCBO 20A/32A, ปั๊มน้ำทิ้ง, กาลักน้ำ, Fire Stop
  5. งานประเมินหน้างาน: รื้อเครื่องเดิม, ขนย้ายเครื่องเดิม, งานสูง, ฐานรอง, กรีดผนัง, เปิดฝ้า, นอกเวลา, วันหยุด
  6. จำนวนเครื่อง → ราคารวมสดทันที (ก่อน VAT / VAT / รวม) → ใส่ใบเสนอราคา
  7. สเปกเครื่องเต็ม: ซีรีส์ ระบบ น้ำยา ขนาดท่อ ขนาด/น้ำหนักคอยล์เย็น-ร้อน ไฟ คอมเพรสเซอร์ รับประกัน

8. Contract Builder — ใช้อัตรา Pricebook จริง

อัตราต่อเครื่อง = CleanRate(แพ็กเกจ, C1 หรือ C2, ประเภท, ช่วง BTU ตาม "ขนาดเครื่องส่วนใหญ่") คอลัมน์อัตรา = อัตรามาตรฐานเท่านั้นบนเว็บ (≥10 เครื่องแสดงข้อความว่าอาจได้อัตราพิเศษ ทีมขายยืนยันในใบเสนอราคา) ต่อรอบ = max(Σ อัตรา × จำนวน, ยอดขั้นต่ำ 4,500) ต่อปี = รอบล้างปกติ × (ครั้งต่อปี − 1) + รอบล้างใหญ่ × 1 (ถ้าเลือก) + ค่าเดินทาง × ครั้งต่อปี แสดงผล = ราคาต่อปีรวม VAT, ก่อน VAT, เฉลี่ยต่อเครื่องต่อปี, ตารางอัตราต่อประเภท

  • งานสูงเกิน 3 ม. พื้นที่ควบคุม เครื่องที่เข้าถึงยาก → แสดงเป็นหมายเหตุ "ประเมินหน้างาน"
  • ด่านกันขาดทุน (ภายใน ห้ามส่งถึง browser): ตรวจยอดต่อทีม-วันเทียบพื้นราคาขั้นต่ำตามนโยบาย (Approval Matrix ในคู่มือทีมขาย) และต้นทุนเต็ม (SBP-MGR-001) — ทั้งสองค่าเก็บเป็น config ฝั่ง server เท่านั้น ไม่ระบุตัวเลขในเอกสารที่ส่งออกนอกบริษัท ถ้าต่ำกว่าให้แสดง "ทีมขายประเมิน" แทนตัวเลข
  • "กำลังคนต่อรอบ" ใช้กำลังทีมจากคู่มือบริษัท §1.9: ติดผนัง 22 · แขวน/สี่ทิศทาง/ตู้ตั้ง 14 · ท่อลม 12 เครื่อง/ทีม-วัน (งานล้างปกติ C1)
