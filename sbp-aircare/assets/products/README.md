# ภาพสินค้าจริง (Rev.09)

ทุกรุ่นบนเว็บมีช่องรูปแล้ว ถ้ายังไม่มีรูป เว็บแสดง "ภาพประกอบ" (ภาพเรนเดอร์ 3 มิติของตัวเครื่องกลางตามประเภท)

## วิธีเพิ่มรูป

1. วางไฟล์ไว้ในโฟลเดอร์นี้ (`assets/products/`)
   - รูปแบบ: `.webp` (แนะนำ) / `.png` / `.jpg`
   - พื้นหลังโปร่งใสหรือขาว กว้าง ≥ 1200 px ตัวเครื่องเต็มกรอบ
   - ตั้งชื่อเป็นตัวพิมพ์เล็ก ไม่มีช่องว่าง เช่น `daikin-ftkb09zv2s.webp`
2. เพิ่มชื่อไฟล์ใน `assets/product-media.json` (ใส่หลายรูปได้ รูปแรกคือรูปหลัก):

```json
{
  "models": { "FTKB09ZV2S": ["daikin-ftkb09zv2s.webp", "daikin-ftkb09zv2s-side.webp"] },
  "series": { "daikin|FTKB / Max Inverter": ["daikin-ftkb.webp"] },
  "brands": { "fujiva": { "wall": ["fujiva-wall.webp"], "cassette": ["fujiva-4way.webp"] } }
}
```

- `models` = รหัสรุ่นตรงกับคอลัมน์รุ่นใน Pricebook (ช่อง SKU บนเว็บ) — แม่นที่สุด
- `series` = `แบรนด์|ชื่อซีรีส์` ตามที่การ์ดสินค้าแสดง ใช้รูปเดียวกันทุก BTU ในซีรีส์
- `brands` = รูปกลางของแบรนด์ต่อประเภทเครื่อง (`wall`, `ceiling`, `cassette`, `floor`)
- รูปเฉพาะรุ่นชนะรูปซีรีส์ และรูปซีรีส์ชนะรูปแบรนด์

3. `npm run build` → รูปถูกคัดลอกไปพร้อมหน้าเว็บ (`dist/*/products/`) และหน้า "ลองวางในห้อง" ใช้รูปจริงได้ (ปุ่ม "ภาพจริงของรุ่น")

⚠️ ใช้เฉพาะรูปที่บริษัทมีสิทธิ์ใช้ (รูปจากผู้แทนจำหน่าย / ถ่ายเอง) — ห้ามดาวน์โหลดรูปจากเว็บผู้ผลิตโดยไม่มีหนังสืออนุญาต
